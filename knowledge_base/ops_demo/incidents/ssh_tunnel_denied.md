# 事故案例：全局允许但 SSH 隧道被拒绝

## 症状

用户报告 SSH 登录成功，但 TCP 隧道建立失败。配置搜索能够找到
`AllowTcpForwarding yes`。

## 易错结论

仅凭全局命中就判断“服务端应允许转发”是错误的，因为该结论没有检查环境 profile、
用户分组、转发方向和目标地址。

## 调查路径

1. 从环境矩阵确定适用 profile；
2. 阅读该 profile 的转发规则；
3. 确认用户分组和转发目标；
4. 必要时请求只读有效配置输出；
5. 将诊断绑定到版本化规则，而不是绑定到本案例摘要。

## 示例答案边界

如果环境是 `current-lab` 且用户属于 `contractors`，应检查
`ssh-policy-b` 中的条件规则。缺少用户分组时，应暂停并追问。
