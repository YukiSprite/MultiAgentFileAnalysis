# 环境与版本矩阵

## 文档身份

- 语料类型：结构化测试基准；
- 权威级别：本文件只负责选择适用的测试 profile；
- 非目标：不得将这里的虚构站点策略用于真实服务器。

## Profile 映射

| 环境 | OpenSSH profile | systemd profile | 站点策略 |
|---|---|---|---|
| `legacy-lab` | `ssh-policy-a` | `unit-policy-a` | `site-policy-2024` |
| `current-lab` | `ssh-policy-b` | `unit-policy-b` | `site-policy-2026` |

## 适用性规则

环境名称是选择规则版本的必要条件。问题未给出环境名称时，不得默认使用
`current-lab`；系统必须请求用户补充环境、软件版本或等价的版本标识。

事故记录中的历史结论不自动适用于其他 profile。只有 profile、作用域和现场状态
同时匹配时，规则才能支持最终诊断。

## 冲突处理

如果故障案例摘要与版本化规则文件冲突，以版本化规则文件为准；故障案例仅提供症状
和调查线索。运行时命令输出属于用户观察，不会覆盖知识库规则。
